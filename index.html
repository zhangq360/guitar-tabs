关于本站

🎼 内置曲谱的来源

本站内置曲谱均为公有领域（Public Domain）作品（如贝多芬《欢乐颂》《致爱丽丝》、传统童谣等），由本站自行编配指法与和声，不存在版权问题，可自由练习与分享。

⚖️ 为什么不「抓取全网曲谱」

网络上的流行歌曲六线谱（如各大谱站的用户上传谱）大多受著作权保护，批量抓取、复制转载会侵犯词曲作者与平台的合法权益。因此本站采用合规方式：自建公有领域曲谱 + 导航到正版资源站点。

🧭 怎么用资源导航

想弹流行歌曲：优先去 Ultimate Guitar / 吉他社 / 弹琴吧搜索正版或用户授权谱；想跟练 Solo：Songsterr 的播放式谱最好用；下载了 .gp 文件：用免费的 TuxGuitar 或 Guitar Pro 打开。

🛠️ 纯前端实现

本站为纯静态网站，六线谱与和弦图均由 JavaScript 实时绘制为 SVG，旋律播放基于浏览器原生 Web Audio API，无需任何服务器与账号，可离线部署。
