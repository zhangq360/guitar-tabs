隐私政策

最近更新：2026 年 9 月

一、我们收集哪些信息

本站是纯静态网站，不要求注册账号，不收集你的姓名、邮箱、手机号等个人身份信息。你搜索曲目、播放旋律、浏览和弦图等所有操作均在你的浏览器本地完成，不会上传到我们的服务器。

二、Cookie 与本地存储

本站自身不使用 Cookie 追踪用户。若未来接入统计或广告服务（如 Google Analytics、Google AdSense），这些第三方服务可能会在你的浏览器中放置 Cookie，用于流量统计与广告展示。你可以在浏览器设置中随时清除或禁用 Cookie，这不会影响本站曲谱浏览、播放等核心功能。

三、第三方服务

  • 资源导航链接：本站链接到 Ultimate Guitar、Songsterr 等第三方网站。你跳转后产生的数据交互由对方网站的隐私政策管辖，本站不参与。
  • 托管服务：本站托管于 GitHub Pages，其服务器日志可能记录常规访问信息（IP、访问时间等），用于安全与运营目的，详见 GitHub 隐私政策。

四、内容版权

本站内置曲谱均为公有领域作品的原创编配。外链资源的版权归各自作者与平台所有。如认为本站内容侵犯了你的权益，请通过 GitHub 仓库（zhangq360/guitar-tabs）提交 Issue 联系我们。

五、政策更新

本政策如有变更，将在本页面更新并修改「最近更新」日期。继续使用本站即表示你同意最新版隐私政策。
